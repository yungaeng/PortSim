# AGV 노면 슬립·CoG 안정성 (2026-10-22)

## 적용 범위

`AGVDynamics`는 실제 운송 AGV와 독립 반복 시험이 공유하는 SI 단위 축약 모델이다. 차체 평면 이동·요, 6개 등가 차륜 접촉점의 회전/타이어 힘, 롤·피치 스프링 상태를 계산한다. 차체 위치를 목표점에 직접 붙이거나 슬립 표시값만 만드는 방식이 아니다. 명령에 의한 크랩 이동은 금지하며 접지력 부족에 의한 물리적 횡슬립을 구분한다.

- 정지/운동 μ는 기존 `Weather_Friction.json`과 실시간 물막·적설·결빙을 공유한다. 정지 μ는 계획에, 슬립에 따라 운동 μ로 전이하는 계수는 실제 접촉력에 사용한다. 타이어 종/횡력 합은 각 접촉점의 μN 한계로 제한한다. 6개 등가 접촉점을 사용하는 다축 조향 모델이며 OEM 타이어 시험으로 식별한 Pacejka 계수 모델은 아니다.
- 차륜 회전관성·구동/제동 토크와 종슬립 강성을 적분한다. 바퀴 원주속도와 차체 접촉점 속도가 다를 수 있다. 휠 거리는 회전량으로 계산한다. IMU는 계산된 평면 가속도와 각속도의 이상적인 합성 관측이며 노이즈·바이어스·통신 지연은 없다. 위치추정은 기존 이상적인 Transponder/관성 보정 가정을 유지하며 실제 융합 필터가 아니다.
- AGV 자체 질량/CoG와 실제로 부착된 모든 화물(20ft 두 개 포함)의 질량·위치를 합산한다. RMG가 인양한 화물은 차량 하중에서 제외한다. 물리 좌표는 **X 전후, Y 좌측, Z 위**이며 CoG는 노면 기준 절대 높이다. 기존 액터의 로컬 +Y 전진/-X 좌측을 한 번 변환한다. 컨테이너 `CoGOffsetCm`는 컨테이너 중심 기준 편차이므로 혼동하지 않는다.
- 좌우·전후 하중과 동적 스프링 반력을 바퀴 하중으로 반영한다. 하중 합을 mg로 보존하고 음의 접촉력은 허용하지 않는다. 바퀴 들림 또는 롤 30도 초과는 **해석 접촉/작은 각도 한계 초과**다. 실제 3D 전복·차체 충돌 이후 거동을 해석한 결과가 아니다. 롤·피치는 상태값이며 차체 충돌체는 평면 자세를 유지한다.
- 안정성 제어는 CoG 높이·좌우 여유·명령 곡률로 속도를 제한한다. 정상 운송의 기존 최고속도/회전속도, FMS 예약, LiDAR 안전 제약도 유지한다. ABS·트랙션 제어는 슬립률을 이용하는 단순 토크 감소 모델이다.

## 조정할 값

에디터에서 `AGV → Physics → Dynamics Settings`를 펼친다. 바퀴 반경 0.7m, 접촉 중심 간격 3.4m, 앞뒤 접촉 간격 9.6m, 바퀴군 회전관성 400kg·m², 공차 CoG 높이 1m, 강성·감쇠·토크 한계는 **조정 가능한 가정**이며 실측 사양이 아니다. 기존 도면의 전체 길이/폭 및 차체 모델 외곽과 접촉 간격을 구분한다. 기존 공차 질량 40t는 `Weather_Friction.json`을 따른다. 불완전한 기하/계수 입력은 제한하고 비유한 동역학 입력은 오류 처리한다.

실제 운송에서는 컨테이너의 질량·CoG를 편집한다. 차량 Payload/DeckCoG는 매 스텝 부착 화물에서 다시 집계하므로 차량 표시값을 바꾸어 화물을 위조하지 않는다.

도로의 중심선 곡률 제한은 기존 프로젝트의 5.8m 규칙을 유지한다. 도면의 내측/외측 회전반경과 이 축약 차량의 중심선 반경이 동일하게 실증된 것은 아니다. 실기기 재현에는 실제 차륜 배치·조향 한계와 내측/외측 반경을 함께 식별해야 한다. 스칼라 조향 관측은 6접촉점 모델의 전륜 두 개 평균이며 개별 접촉점의 각도도 내보낸다. 부착 화물의 속도는 바퀴 기반 차체 병진과 실제 요 각속도에서 계산하며, 예전 등가 조향각으로 요 속도를 역산하지 않는다.

동역학 운송 검증에서 발견된 경로 추종 문제도 보완했다. 첫 노드는 경로 시작점을 고정해 통과 평면을 판정하며, 회전 중에는 경로를 교체하지 않는다. 둥글게 가공한 우회 경로도 전체 차체로 경계를 검사하고, 너무 짧아 원호를 만들지 못한 직각 코너나 현재 진행방향을 즉시 뒤집는 후보는 채택하지 않는다. 코너 감속에는 0.4초의 응답 여유를 둔다. 도로 경계·물리 차체 충돌·최종 도킹 위치/각도 기준은 완화하지 않는다.

## 독립 시험 실행과 웹 확인

1. `PortSim/Config/AGV_PhysicsBench.json`에서 시험별 조건을 바꾼다. 기본 사례는 같은 6m/s·30t 조건의 건조/젖음/결빙 제동, 중앙/편심/높은 편심 CoG 선회와 안정성 제어 적용 선회다. 제동 토크 차이를 드러내는 6m/s² 요청은 정상 운송의 서비스 제동과 별개의 시험 입력이다. 제동 비교는 ABS OFF로 조건을 통일한다.
2. 빌드 후 `./PortSim/Scripts/TestAGVDynamics.ps1` 실행. 이 명령은 월드 운송과 분리된 자동화 시험을 실행하고 `PortSim/Saved/Tests/AGVDynamics_Report.json`을 생성한다. 콘솔이 아니라 프로젝트 루트의 PowerShell에서 실행한다.
3. 웹 **AGV 물리 시험**에서 제동거리·시간, 최대 슬립, LTR, 종료 원인과 0.1초 간격 기록을 확인한다. 보고서는 생성 시각이 표시되는 과거 시험 결과다. 웹이 시험을 실행하거나 현재 터미널을 위험 조건으로 바꾸는 기능은 아니다. 설정을 바꾼 뒤 명령을 다시 실행한다.
4. 실시간 값은 장비 탐색기 → AGV → **물리 모델/센서**에서 확인한다. 정상 운송에서는 CoG 안정성 감속과 기존 2.5m/s 회전 제한이 함께 적용되어 전복이 발생하지 않을 수 있다. 독립 선회 시험은 비교를 위해 현장 회전속도 제한을 사용하지 않으며 접촉 한계에 도달하면 종료한다. 파라미터에 따라 한계에 도달하지 않을 수도 있다.

제동 시간·거리는 물리 제동 시작부터 저속 정지 기준(0.005m/s)까지 적분하며 진행 중/완료를 구분한다. FMS·일반 차량 LiDAR·도킹 기어변경·충돌 롤백의 기존 강제 정지는 별도의 제약이고 진행 중 제동 기록을 무효화한다. 2026-10-24에 작업자 감지 후 연속 물리 제동, 스캔/반응 지연, 데크 마찰/화물 이동·고정장치 반력을 통합했다. 실행 방법과 범위는 [AGV_Emergency.md](AGV_Emergency.md)를 참고한다. 수막현상, 노면 경사/요철, 개별 서스펜션의 상세 기구, 타이어 온도·마모도 이번 범위에 없다.

## 모델 참고

- [MathWorks Combined Slip Wheel](https://www.mathworks.com/help/vdynblks/ref/combinedslipwheel2dof.html): 종/횡 타이어 힘과 차륜 회전의 결합 개념. 이 프로젝트의 계수 출처는 아니다.
- [MathWorks Vehicle Body 6DOF](https://www.mathworks.com/help/vdynblks/ref/vehiclebody6dof.html): 차체 CoG·기하·힘/모멘트 분리 참고. PortSim은 전체 6DOF 강체 모델을 구현한 것이 아니다.

## 최종 검증 (2026-10-22)

- UE 5.6 빌드 성공. 최종 네이티브 36개 PASS(`AGVPhysics_FinalUnits.log`). 웹 전체 22개 PASS 후 최종 AGV 표시 보완은 관련 3개 시험을 다시 확인했다. 구현을 마친 뒤 한 검증 단계에서 실행했으며, 발견된 도로 경계·첫 노드 통과·짧은 우회 코너 문제를 수정한 뒤 필요한 회귀 검증을 재실행했다.
- 독립 시험 7개 PASS. 아래 제동 비교는 같은 초기 속도 6m/s, 화물 30t, CoG=(0,0,3.495)m, 제동 요청 6m/s², ABS OFF 조건이다. 실제 AGV의 검증된 제동 성능표가 아니다.

| 노면 | 정지/운동 μ | 제동거리 | 제동시간 |
| --- | --- | --- | --- |
| 건조 | 0.80 / 0.65 | 3.655m | 2.054s |
| 젖음 | 0.50 / 0.40 | 4.457m | 2.263s |
| 결빙 | 0.08 / 0.05 | 29.548m | 10.187s |

- 선회 시험의 최대 |LTR|는 중앙 CoG 0.491, 편심 CoG 0.760, 높은 편심 CoG 0.875, 높은 편심+안정성 제어 0.728이다. 이 기본 선회 4개는 접촉 한계에 도달하지 않았으며 3D 전복이 재현됐다는 의미가 아니다. 접촉 한계 검출·음의 접촉력 배제는 네이티브 시험으로 확인했다.
- 정상 운송 회귀 PASS: 600개 중 120개(20%) 운송 및 AGV 복귀, 9개 STS 모두 완료. 마지막 적재 9,722.250145 시뮬레이션 초, 복귀 완료 9,916.2초. 상부 지지 적재 58건, 20ft 두 자리 적재층 13개와 규격별 구역 분리를 확인했다. 두 20ft 화물의 동시 운송은 이 실행에서 성립하지 않았다. 건조·선박 운동 OFF, 기존 바람 적용 조건이며 전체 600개 완료나 정상 대비 성능 개선을 입증하는 시험은 아니다.
- 실행 명령: `./PortSim/Scripts/TestSite.ps1 -Mode Normal -PlaybackRate 0 -FixedFPS 5 -TimeoutMinutes 60 -NoSea -CheckStowage -ResultSummaryPath ./PortSim/Saved/Tests/AGVPhysics_Normal120.json`.
- 산출물: `PortSim/Saved/Tests/AGVDynamics_Report.json`, `AGVPhysics_Normal120.json`, `AGVPhysics_Runtime_Snapshot.json`, `AGVPhysics_Bench_Web.png`. 통합 로그는 `PortSim/Saved/Logs/SiteTest_Normal_Depot_Reused_41372.log`다. 웹 보고서 표와 실시간 AGV의 하중·CoG·IMU 표시도 브라우저에서 확인했다.
