# 웹 터미널 오버뷰 (2026-10-24)

기존 화면은 야드에 일정 화면 간격으로 13열을 배치하고, 장비는 다른 좌표 변환으로 그려 AGV가 야드 위를 지나는 것처럼 보일 수 있었다. 새 화면은 엔진 세계 좌표(미터)를 SVG 좌표로 그대로 사용하며 `preserveAspectRatio="xMidYMid meet"`로 가로·세로를 같은 비율로 확대한다. 축은 X 내륙 방향, Y 부두축 방향이며 실제 지리상의 북쪽으로 정의하지 않는다.

## 배치 데이터

`DashboardLayout.cpp`는 `PortSim.DGT.SiteBlockout` 액터의 `Site_Roads`, `Site_Markings`, `Site_YellowMarkings`, 큰 `Site_Buildings` 인스턴스의 실제 세계 위치·회전·메시 크기를 캡처한다. 이미 면적 보정이 적용된 실제 인스턴스에 `SiteX`를 다시 적용하지 않는다. 배경 색 구분은 웹 표현이고 배치·크기는 엔진 값이다. 슬롯 구획은 `TerminalSite.cpp`와 동일한 `TerminalLayout` 함수를 사용한다.

- 블록 23개, 블록마다 Bay 0~12의 짝수 7열과 Bay 18~28의 짝수 6열을 표시한다. 비운 Bay 14/16 공간을 야드 칸으로 덮지 않는다. 각 칸은 실제 길이와 7행×3m 구획을 사용하고, 20ft 칸은 두 자리로 나눈다.
- 중앙도로는 `CentralRoadY=-160m`, 폭 16m이며 블록 01~09와 10~23 사이 공간을 그대로 둔다. 7열/6열 사이의 공간과 서로 다른 구역이다. 빈 공간 전체를 임의 도로로 채우지 않는다.
- 야드의 모든 칸을 가짜 컨테이너로 채우지 않는다. 실제 `state=Yard` 화물만 실제 크기·위치·회전으로 덧그린다.
- AGV는 4.2×14.6m 실제 차체 외곽을 실제 위치·yaw로 그린다. 클릭 영역은 투명하게 넓히지만 표시 위치나 외곽은 옮기지 않는다. STS/RMG는 현재 다리·보·트롤리의 실제 메시 외곽과 스프레더 위치를 사용한다.
- 기존 고장/영향 원과 실제 남은 FMS 경로, 돌발시험 작업자도 같은 미터 좌표 위에 표시한다. 완료된 재배정 표시를 지우는 규칙은 유지한다.

정적 배치는 실행당 한 번 `PortSim/Saved/Dashboard/layout-<run_id>.json`으로 원자적으로 저장하여 매초 도로 인스턴스를 다시 수집하지 않는다. `/api/terminal-layout`은 현재 상태의 실행 ID에 해당하는 파일만 제공한다. 다른 실행의 배경을 현재 장비와 합치지 않는다. 새 배치 파일이 없으면 임의 배경 대신 새 빌드 실행 안내를 표시한다. 런타임 중 정적 사이트 메시를 편집했다면 새 실행으로 배치를 다시 캡처한다.

## 보기와 적용

새 엔진 빌드로 한 번 실행하고 웹을 새로고침한다. **전체 / 야드 / 중앙 공간 / 선석 / 주차장**은 동일한 좌표를 확대해서 보는 기능이며, 야드나 장비 위치를 보기 좋게 재배열하지 않는다. 중앙 공간 보기는 중앙도로를 중심으로 위아래 140m를 확대해 7열/6열 사이 간격도 볼 수 있다. 선택한 세계 좌표 범위 밖 도형은 클리핑하여 여백에 다른 구역이 비쳐 보이지 않게 한다. 축척 막대는 같은 SVG 미터 좌표로 계산한다. 지도 액터/야드 칸 클릭은 기존 상세 화면으로 연결된다. AGV 경로·스케줄·주행 물리를 바꾸는 수정은 아니다.

검증은 구현 후 웹 회귀, 네이티브 배치 시험, 실제 엔진 배치 내보내기 및 브라우저 표시를 한 단계에서 수행한다. 네이티브 배치 시험은 23×13열, 7열/6열의 실제 간격, 16m 중앙도로, 실제 메시의 미터 단위·회전과 캡처 소유권을 확인한다. 웹 시험은 회전된 AGV·경로의 좌표 일치, 빈 슬롯/실제 화물 구분, 확대 시 좌표 보존, 실행 ID 불일치 차단을 확인한다.

2026-10-24 최종 검증: UE 5.6 빌드 성공, 웹 회귀 31개·네이티브 회귀 39개 통과. 브라우저 검증에서 발견한 확대 여백 클리핑을 보완한 뒤 관련 웹 4개를 다시 확인했다. 실제 엔진에서 23블록/299열, 포장면 인스턴스 1,115개, 차선·구획선 7,964개, 건물 10개를 내보냈다. 정적 선은 웹에서 합친 SVG 경로로 캐시해 매 갱신마다 수천 개 DOM 노드를 생성하지 않는다. 야드 09 클릭 → 정확한 13열 강조 → 상세 정보 연결을 브라우저에서 확인했다.

지도 확인용 엔진만 잠시 실행하여 이동 장비와 배치를 확인한 뒤 종료했다. 이번 지도 변경에 대해 장시간 운송 시험을 다시 수행한 것은 아니다. 증거는 `PortSim/Saved/Tests/TerminalMap_Runtime.json`, `TerminalMap_Layout.json`, `TerminalOverview.png`이며 로그는 `PortSim/Saved/Logs/TerminalMap_FinalUnits.log`, `TerminalMap_Preview.log`다. 기존 AGV 돌발상황 통합의 120개 운송 회귀 기록은 별도 문서에 유지한다.
