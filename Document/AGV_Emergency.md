# AGV 돌발상황 통합 (2026-10-24)

## 연결 범위

`AGVEmergency`가 기존 `AGVDynamics` 타이어·편심 CoG·하중 이동 솔버에 작업자 장애물, LiDAR 스캔/반응 지연, 급제동 토크, 데크 접촉을 연결한다. 실시간 차량과 독립 반복 시험이 같은 제어 상태와 타이어/화물 계산을 사용한다.

작업자는 t=0에 진행 차로를 점유한 뒤 정지하는 시험 장애물이다. 차체 선단부터 작업자 표면까지 거리, 차폭, 설정된 LiDAR 거리와 스캔 주기로 감지한다. 감지 후 반응 시간이 지나면 속도 목표 0과 급제동 요구를 입력한다. 바퀴·차체 속도를 즉시 0으로 만들지 않는다. 제동 시작 이후 실제 차체 이동거리를 별도로 적산하며 반응 중 이동거리도 총 이동거리에 포함한다. 작업자 접촉, 화물 이동 한계, 고정장치 과부하, 바퀴 접촉 한계, 시간 초과를 안전 정지와 구분한다.

화물은 평면 병진 접촉 모델이다. 정지 마찰은 요구 접촉력까지, 미끄러지는 동안은 운동 마찰 μN까지 작용한다. 차량+화물의 합성 질량 중심 속도를 외력으로 적분하고, 화물의 상대 이동만큼 차체 위치·접촉점 속도를 보정하므로 내부 마찰력이 시스템 병진 운동량을 추가 생성하지 않는다. 이동한 화물 위치를 합성 CoG·바퀴 하중에 다시 반영한다. 차체 IMU는 화물 상대 가속도 보정도 포함한다.

고정 화물은 이상적 구속이 상대 이동을 막고, 데크 마찰을 넘는 요구력을 고정장치 반력으로 기록한다. 반력이 설정 용량을 넘으면 시험을 종료한다. 고정장치가 저절로 풀리거나 화물이 무조건 미끄러지도록 만들지 않는다. 미고정 화물에서만 실제 화물 액터를 계산된 상대 변위로 이동시킨다. 컨테이너 자체 질량은 실제 적재 화물을 사용한다.

## 실제 터미널에서 시험

1. 새 엔진 빌드 후 시뮬레이션을 실행한다. 웹에서 AGV 선택 → **오류·복구 → AGV 돌발상황 통합 시험**.
2. 40ft 한 개를 싣고 야드로 이동하는 AGV의 긴 직선 구간에서 **고정 화물 시험** 또는 **미고정 화물 시험**을 누른다. 속도 1m/s 이상, FMS/일반 LiDAR 대기 아님, 직선 주행, 도로 예약 확보가 필요하다. 엔진에서 작업자 위치+10m 이상의 직선 예약 구간도 확인하며 부족하면 거절 사유가 표시된다. 빈 차량·20ft 두 개·45ft는 현재 통합 주입 대상이 아니다.
3. 선택 AGV의 노면과 CoG에 지역 시험값을 적용한다. 기본 젖음 1, 결빙 0, 화물 중심 기준 CoG 편차 X=0/Y=좌측 0.8/Z=위 0.5m다. 터미널 전체 비·눈 설정을 바꾸는 명령이 아니다. 에디터 **AGV → Emergency Test**에서 젖음·결빙·CoG·작업자 거리·스캔 주기·반응 시간·급제동 요구·이동 한계·고정장치 용량을 조정한다. 마찰계수는 기존 `Weather_Friction.json`의 Tire/Steel과 해당 시험 노면에서 계산한다.
4. 언리얼에는 고정된 시험 작업자 블록과 라벨이 표시되고, 웹 터미널 오버뷰에는 빨간 **시험 작업자** 점이 나타난다. AGV 물리 모델/오류·복구 화면에서 감지 시간, 제동 시작, 정지거리, 슬립, LTR, 관성력·반력, 화물 이동을 확인한다. 기존 경로 예약을 유지하며 경로 진행·인계·교착 복구는 시험 차량에 적용하지 않는다. 주변 차량은 기존 FMS/LiDAR로 반응한다.
5. 안전 정지·화물 위치 유지가 확인되면 **안전 정지 시험 해제**로 장애물을 제거하고 원래 CoG·실제 환경으로 복귀하여 기존 경로를 계속한다. 완료 요약은 다음 시험/초기화까지 보존되고 시작·종료 이력도 남는다. 화물 이동, 작업자 접촉, 고정장치/접촉 한계 초과, 외부 강제 정지 무효화는 해제로 운송을 재개할 수 없으며 시뮬레이션을 초기화한다. 안전 한계로 종료한 경우 전체 안전 정지 사유가 표시된다.

## 반복 시험

`PortSim/Config/AGV_EmergencyBench.json`의 defaults와 cases를 바꾸고 빌드 후 `./PortSim/Scripts/TestAGVDynamics.ps1`을 실행한다. 기존 단독 시험 7건과 통합 사례 8건을 생성한다. 결과는 `PortSim/Saved/Tests/AGVEmergency_Report.json`, 웹 **AGV 물리 시험 → 돌발상황 통합 시험**에 표시된다. 보고서는 과거 독립 시험이며 웹에서 보고서 조회만으로 현재 터미널에 사고를 주입하지 않는다.

기본 통합 사례: 건조/젖음 고정 화물, 결빙 제동 부족, 젖음 미고정 화물 이동, 중앙 CoG 비교, 근거리 작업자·늦은 반응, LiDAR 시정 1m, 고정장치 용량 부족. 위험 사례의 `expected`는 예상된 종료 원인이므로 `valid:true`가 안전함을 뜻하지 않는다. 시간별 속도·감지·제동·이격·슬립·좌우 하중·화물 이동·데크 힘도 저장한다.

## 해석 한계와 가정

이 단계는 전체 차량/화물의 3D 강체 해석이 아니다. 화물 회전·낙하·주변 구조물과의 접촉, 고정장치 탄성/유격/파괴 이후, 차체 3D 전복 이후는 계산하지 않는다. 롤·피치는 기존 등가 스프링 모델이며 화물 미끄럼과 서스펜션의 상세 기구 결합을 식별한 모델은 아니다. LiDAR는 기하학적 감지이고 광학·반사율·센서 오류 확률이나 작업자의 보행 모델은 없다. 실제 운송에 주입하는 시험은 직선 시작으로 제한하며, 감지 거리는 시작 시 정상 운송에서 관측한 가시거리 한계를 사용한다.

기존 일반 AGV 간 LiDAR·FMS 예약·도킹 강제 정지 가드는 유지된다. 이번 물리 급제동은 명시적으로 주입한 작업자 시험에 적용된다. 외부 강제 정지에 의해 바뀐 시험은 무효로 판정한다. 모든 접촉/타이어/고정장치 용량·스캔/반응 시간은 실측 인증 사양이 아닌 편집 가능한 가정이며 안전 인증이나 실제 장비 제동 성능 보증으로 사용하지 않는다.

모델 개념 참고: [MathWorks Translational Friction](https://www.mathworks.com/help/simscape/ref/translationalfriction.html), [MathWorks Vehicle Body 6DOF](https://www.mathworks.com/help/vdynblks/ref/vehiclebody6dof.html). 프로젝트 계수는 이 문서에서 식별한 값이 아니다.
