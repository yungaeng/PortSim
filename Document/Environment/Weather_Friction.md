# 날씨에 따른 장비 마찰 모델

통합 터미널의 AGV·STS·RMG에 적용한다. 기본은 건조 상태이며 기존 바람·돌풍·선박 운동과 함께 계산한다. 물막과 적설을 시간에 따라 누적하고, 배수·증발·융해 후 남은 표면 상태로 마찰계수를 계산한다.

## 설정

- `PortSim/Config/Weather_Friction.json`: 타이어/노면, 차륜/레일, 금속 접촉의 정지·운동 마찰계수 및 운용 가정.
- 날씨 실행 인수: `-PortSimRain -PortSimRainRate=25`, `-PortSimSnowWeather -PortSimSnowRate=30`, `-PortSimIcing -PortSimIceIntensity=1`. 강우는 물 mm/h, 강설은 눈 깊이 mm/h이며 서로 같은 수분량을 뜻하지 않는다. 기존 `-PortSimSnowIntensity=0.3`도 지원하며 기본 최대 강설량 100mm/h의 30%를 뜻한다.
- 초기 노면 입력: `-PortSimWetness=1`, `-PortSimSnow=0.5`, `-PortSimIce=0.2`. 각각 0~1이며 기본 0이다. 초기 저장량을 설정하며 이후 배수·융해한다. 영구적인 최소 피복률이 아니다. 별도 설정 파일은 `-PortSimFrictionConfig="절대 경로"`로 지정한다.
- 에디터: **플레이 중 월드의 QuayCrane → Environment 컴포넌트 → Friction Settings**에서 Tire/Rail/Steel 계수와 Surface Dynamics를 편집하면 현재 장비에 반영된다. Environment / Surface의 Wetness/Snow/Ice를 직접 바꾸면 현재 저장량도 재설정된다. 시작 시에는 JSON 설정이 계수에 우선 적용된다. 플레이 중 변경은 에디터 종료 후 자동 저장되지 않는다.
- 언리얼 환경 패널: 비·눈·결빙 ON/OFF와 강도 변경은 즉시 입력에 반영되고, 표면은 시뮬레이션 시간에 따라 변한다. 눈 행은 강설량과 현재 적설 깊이를 함께 표시한다. 일시정지하면 배수·누적 시간도 멈춘다. 날씨 입력 설정은 다음 실행 때 복원되지만 누적된 노면 저장량은 새 실행으로 이어 저장하지 않는다.
- C++ API: 비는 `SetRainEnabled/SetRainfallMmPerHour`, 눈은 `SetSnowEnabled/SetSnowfallMmPerHour`, 결빙은 `SetIceEnabled/SetIceIntensity`. Blueprint에서도 노출된 강도/토글 함수를 사용할 수 있다. `SetSurfaceConditions`는 현재 표면을 재설정하고 `SetWaterFilmMm/SetSnowDepthMm`는 물막/적설 실측량을 직접 입력한다. `SetFrictionSettings`로 계수를 실행 중 교체한다. `GetSurfaceConditions`는 현재 누적 결과다. 안개 자체는 마찰을 낮추지 않고 센서 탐지거리에 적용한다.
- HUD와 웹 장비 상세의 **물리 모델**에 물막 두께, 적설 깊이, 건조도, 젖음/건조 변화율과 현재 μ·구동 제한·안착 판정이 표시된다. 건조도는 `1 - 젖음 비율`이며 얼음·눈이 없다는 의미는 아니다.

계수는 건조→젖음→적설→결빙 순서의 선형 혼합으로 계산한다. 서로 배타적인 강수 확률이 아닌 해당 표면의 상태/피복률이다. 수치들은 **모두 시뮬레이션 가정이며 현장 실측값·제조사 보증값이 아니다.** 영하 온도로 자동 결빙시키지 않는다.

## 누적과 건조

물막 W(mm)는 `dW/dt = 강우 + 눈 융해수 - 얼음 생성에 사용되는 물 - 증발 - ln(2)/배수반감기 × W`로 계산한다. 초 단위 적분 시 mm/h를 mm/s로 변환한다. 기본값은 완전 젖음 물막 0.5mm, 최대 물막 5mm, 배수 반감기 600초, 증발 0.5mm/h다. 젖음 비율은 `clamp(W/0.5, 0, 1)`이다. 비가 멈춰도 W는 남고, 배수·증발로 서서히 줄어든다.

눈 깊이는 강설량을 누적한다. 강설 중에는 추운 조건으로 가정해 동시에 녹이지 않고, 강설이 멈추면 기본 20mm/h로 녹는다. 눈 깊이 10mm를 완전 피복, 최대 깊이는 500mm로 가정한다. 녹은 눈은 눈 깊이의 10%만큼 물로 전환한다. 강설 슬라이더의 최대값은 100mm/h이며 설정할 수 있다.

결빙 ON 강도는 외부에서 주는 목표 피복률이다. 생성은 완전 피복 기준 120초, 해빙은 1800초 속도로 목표에 접근하며 물막과 물당량 1mm를 교환한다. 외부 결빙 조건은 물막이 없어도 부착빙을 만들 수 있는 가정이다. 기온·일사·습도·노면 재질별 열수지나 물의 상변화 에너지 보존을 해석한 모델은 아니다. 해빙수는 물막에 더해진다.

모든 시간은 시뮬레이션 시간이다. 4배속이면 실제 1초 동안 누적·건조도 4초 진행한다. 일정 입력 구간은 해석식으로 적분하고 눈 소진/얼음 목표 도달 시점을 분리해 큰 시간 간격과 작은 시간 간격의 결과를 맞춘다. 비·눈을 끄는 동작은 저장량을 지우지 않는다. 시뮬레이션이 일시정지해도 명시적인 계수·표면 편집은 적용되며, 시간에 따른 변화는 재개 후 진행한다.

기존의 일괄 20% 강우 감속은 제거했으며, 실제 마찰 한계가 장비 사양 한계보다 낮을 때만 구동 제한이 줄어든다. 계수와 노면은 매 프레임 장비 제어에 전달한다. 공유 물리 재질은 하나를 재사용하고 Chaos 재질 핸들의 계수를 갱신하므로 누적이 진행되어도 매 프레임 UObject를 만들거나 모든 컨테이너에 재질을 다시 바인딩하지 않는다.

| 접촉 | 건조 정지/운동 μ | 젖음 | 적설 | 결빙 |
|---|---|---|---|---|
| 타이어/노면 | 0.80 / 0.65 | 0.50 / 0.40 | 0.20 / 0.15 | 0.08 / 0.05 |
| 차륜/레일 | 0.25 / 0.20 | 0.12 / 0.09 | 0.07 / 0.05 | 0.03 / 0.02 |
| 금속 접촉 | 0.40 / 0.30 | 0.20 / 0.15 | 0.12 / 0.08 | 0.05 / 0.03 |

## 실제 적용 범위

AGV는 정지 마찰 기반 접지력 `μ × (공차 질량 + 적재 질량) × g`의 80%를 사용 한도로 둔다. 바람/공기저항을 보수적으로 차감하고, 선회 가속도 `v²/R`와 종방향 가속도가 같은 마찰 한계를 공유하게 한다. 구동축 하중 비율과 구름저항을 가속에 반영한다. 제동에는 접지력의 절반을 확보하고 나머지를 조향 여유로 둔다. 기존 사양의 가속·속도 상한도 유지한다. FMS 코너 진입 감속과 LiDAR의 계산 정지거리는 이 제동 한계를 사용한다.

AGV 주행은 2026-10-22 확장에서 6개 등가 차륜의 회전/토크·종횡 슬립·CoG 하중 분배를 사용하는 축약 동역학으로 변경했다. 운동 μ도 실제 타이어 힘에 사용하며 단순 ABS/트랙션 및 CoG 안정성 속도 제어를 적용한다. 상세 가정과 독립 시험은 `AGV_Physics.md`를 참고한다. 수막현상과 3D 전복 후 거동은 미구현이다. FMS 예약/충돌 방지와 LiDAR의 기존 즉시 정지 처리는 남아 있으므로 계산 제동거리·완료한 물리 제동 기록을 모든 비상정지 결과로 해석하면 안 된다.

STS·RMG의 트롤리/갠트리 수평 가감속과 정지거리에는 차륜/레일의 접지 한계를 적용한다. 현재 모델은 전체 지지하중을 이용할 수 있는 구동/제동축을 가정한다. 권상 속도·케이블·드럼·모터 모델은 기존 계산을 유지한다. 크레인 구조물 전체의 풍압/레일별 하중이동은 새로 해석하지 않는다.

스프레더는 잠금 전 안착에서 `μ × 안착 수직하중`을 검사한다. 수직하중은 스프레더 자중의 10%가 접촉면에 실린다는 가정이고, 나머지는 호이스트가 지지한다. 필요 접선력은 잔류 상대속도를 코너 허용오차 거리 안에 줄이는 힘, 선박 가속, 기울기에 따른 중력 성분, 스프레더 풍압을 합친다. 부족하면 코너 안착 신호와 잠금 진행을 허용하지 않아 기존 재정렬/재시도·실패 절차가 작동한다. 4개 트위스트록으로 부착된 뒤에는 기계적 결합을 유지한다. 접촉 변형·코너별 접촉압력 솔버는 아니다.

컨테이너, AGV 데크, 크레인 받침대 등 충돌 가능한 부품에는 공유 Chaos Physical Material의 금속 정지·운동 μ를 적용한다. 결합 규칙은 Min이다. 장비 등록 때 같은 재질을 바인딩하고 노면 변화 시 공유 Chaos 핸들을 갱신한다. 화물이 장비에 고정된 운반 단계에서는 Chaos 마찰로 미끄러지지 않는다. 20/40/45ft 화물의 기존 풍압도 실제 외형 치수를 사용하도록 맞췄다.

## 근거와 한계

- [FHWA 젖은 노면 운용 지침](https://highways.fhwa.dot.gov/safety/speed-management/guidelines-use-variable-speed-limit-systems-wet-weather/chapter-2-driver): 수분 등으로 노면 마찰과 정지거리 조건이 변한다는 모델 방향의 근거. 위 μ 숫자의 출처는 아니다.
- [Epic Physical Materials](https://dev.epicgames.com/documentation/en-us/unreal-engine/physical-materials-reference-for-unreal-engine): 마찰 및 접촉 재질 결합 규칙. 구현 API는 설치된 UE 5.6 헤더 기준이다.
- [Bromma landing and hold indication](https://bromma.com/prevent-accidents-with-bromma-landing-and-hold-indication-system/): 안착 확인과 트위스트록 잠금의 구분. 현재 기종에 해당 제품이 장착되었다는 뜻이 아니다.

재현 검증: `TestSite.ps1 -Mode Normal -Wetness 1 -PlaybackRate 4` 등으로 시작 상태를 지정할 수 있다. 일반 통합 검증은 600개 중 120개(20%) 인계 및 복귀를 확인한다. 결빙에서 픽업이 실패한다면 무조건 성공시키도록 마찰 조건을 낮추지 말고 입력 조건과 안착 수직하중 가정을 확인해야 한다.
