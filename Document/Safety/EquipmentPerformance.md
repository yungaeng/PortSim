# 장비 탐색기 운용 지표

장비 탐색기 표의 작업/위치 오른쪽에 가동률(%), 크레인 생산성(개/h), 선석 생산성(개/선석·h)을 표시한다. 항만 모니터링의 작은 표는 기존 열 구성을 유지한다.

- **장비 가동률** = 실제 작업시간 / 관측 운용시간 × 100. STS/RMG는 이동·인양·착좌·잠금·안착 확인 등 정상 작업 구간을 누적하고 AGV 인계 대기, 오류, 운용 차단을 제외한다. AGV는 운반/공차 이동 및 크레인과의 실제 인계 동작을 누적하며 FMS 대기·충전·센서/구동 고장·돌발상황 정지는 제외한다. R/S는 실제 복구 주행/유압 동작을 누적한다. 단순 busy 상태 전체를 작업시간으로 계산하지 않는다. 누적은 물류 제어 간격(50ms)의 상태 관측 기준이다.
- **크레인 생산성** = 해당 STS/RMG의 완료 컨테이너 수 / 관측 운용시간(시간). 20/40/45ft는 각각 컨테이너 1개로 계산한다. 실제 작업시간만을 분모로 사용한 순생산성이 아닌, 대기까지 반영한 관측 구간 생산성이다.
- **선석 생산성** = 해당 선석의 하역 인계 완료 + 선박 적재 완료 컨테이너 수 / 해당 선석 작업시간(시간). 선석의 첫 작업 배정부터 마지막 계획된 하역 인계/선박 적재 완료까지 측정하고, 진행 중에는 현재까지 경과시간을 쓴다. 작업이 끝난 선석은 종료시각을 고정한다. 각 화물의 최초 STS 그룹으로 선석을 식별해 재배정에 의한 중복이나 선석 간 이동을 방지한다. 같은 선석의 STS 3대는 같은 선석 생산성을 공유하며 선박 행에도 표시한다.

관측 시간은 엔진 운용 시뮬레이션 시계를 사용한다. 관측 구간의 대기·고장·기상/비상 정지를 포함하며 수동 일시정지, 실행 전/후의 시간은 제외한다. 선석 시간도 같은 시계의 두 시각 차이다. 전체 리셋 시 누적값을 초기화하며 체크포인트에 포함한다.

AGV/R/S에는 크레인 생산성, RMG/AGV/R/S에는 고정 선석 생산성을 표시하지 않는다. 화물·야드·기타 액터에는 해당 지표가 없다. 관측시간 0 또는 이전 엔진 기록은 `—`이고, 관측시간이 있는 정상 대기 장비의 0% / 0개/h와 구분한다. UI의 값에 마우스를 올리면 적용 분모와 선석을 확인할 수 있다.
