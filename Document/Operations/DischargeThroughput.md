# STS 하역 처리량 진단과 개선

## 확인한 병목

시간당 25~30개라는 사용자 목표는 대기까지 포함한 사이클 120~144초다. 장비의 최고 속도를 올리거나 배속을 높여 이 값을 맞추지 않는다.

최근 120개 실제 운송 기록 `Site_020653B04292555F7C371491010123F1.csv`에서는 STS 사이클 평균이 343.91초, 인양 후 AGV 대기가 42.98초였다. 대기를 빼도 300.93초로, 운송 알고리즘 외에 크레인 제어 자체도 느렸다. 전체 마지막 야드 적재까지의 공통 구간으로 계산하면 STS 9대 평균 5.11개/시뮬레이션 시간이다.

- 기존 수평 위치 제어는 장거리 이동 끝에서 작은 위치 이득으로 오래 수렴했다. 각 단계에서 위치·속도·흔들림 조건을 통과해야 하므로 이 지연이 반복됐다.
- 야드 배정은 빈 바닥 자리에 600초 상당의 비용을 가산했다. 기존 스택을 선호하는 보상이 커, 다른 RMG와 바닥 자리가 있어도 선행 적재/접근권 해제를 기다리는 계획이 생겼다.
- 빈 AGV의 STS 직접 복귀는 목적 STS가 이미 비어 있어야 검토됐다. 별도 대기 베이에 먼저 도착할 수 있는 구조인데도 현재 STS 작업과 복귀 이동을 겹치지 못했다.

## 변경

1. **와이어 길이에 맞춘 수평 이동 피드백**: 측정된 드라이브 위치·속도와 흔들림 각도·각속도로 트롤리/진자 4상태 폐루프를 구성한다. 극점은 두 2차 다항식으로 지정하고 측정 와이어 길이와 권상 속도에 맞춰 이득을 계산한다. 속도·가속도·제동 거리·흔들림 제한과 실제 모터/와이어 플랜트는 그대로 적용한다. 센서 집기, 물리 착좌, 4개 잠금, 시험 권상, 하중, 착지 검사는 생략하지 않는다. 움직이는 선박의 빈 스프레더 접근/집기는 기존 이동 표적 추종 제어를 유지한다.
2. **완료 예상 시각으로 야드 선택**: 도로를 경유하는 운송 거리, 해당 STS의 계획된 작업, RMG 접근권 점유, 아래 컨테이너의 예상 적재, 빈 AGV의 출구 이동을 비교한다. 크기·출고 순서·위험물·냉동·하중·20ft 두 받침 조건은 기존 하드 제약이다. 스택/20ft 짝 선호는 예상 대기보다 작게 제한한다. 계획은 예측일 뿐, 런타임 예약과 센서가 다시 허용 여부를 판단한다.
3. **빈 AGV 직접 복귀 선예약**: STS가 작업 중이어도 다음 실행 가능한 화물이 있고 도로 ETA가 유리하면, 야드에서 이미 돌아오는 빈 AGV 한 대를 기존 STS 대기 베이에 예약한다. 실제 STS 접근/인양은 기존 소유권 해제와 야드 접근권 확보 후 시작한다. 주차장에서 추가 대기 차량을 무제한 출발시키지 않는다.
4. **처리량과 단계 시간 분리 표시**: 웹 STS 개요에 선박→AGV 인계, 최종 야드 완료, 완료 사이클 평균, AGV 대기, 단계별 평균을 표시한다. 기준은 배속과 무관한 공통 시뮬레이션 시간이다. 현재 작업의 부분 시간을 완료 사이클 평균에 섞지 않는다. 로그 `CRANE_CYCLE`에 8단계 시간을 기록한다.

`STS_Simulation.json`, `RMG_Simulation.json`의 `dynamics.travel_response_ratio=0.55`는 검증된 제조사 설정이 아닌 시뮬레이션 제어 설계값이다. 0이면 기존 피드백을 사용한다. 2차 응답 감쇠비 0.85, 다른 모드 주파수 비 1.5 역시 설계 가정이다. anti-sway가 꺼져 있으면 이 제어가 임의로 다시 켜지지 않는다. 야드 예측의 STS 144초/RMG 180초, 바닥 비용 45초·20ft 짝 보상 90초도 계획용 가정이며 실제 시간을 강제로 설정하지 않는다. 전역 최적해나 실장비 인증을 주장하지 않는다.

## 2026-10-27 운송 결과

같은 초기 선박 3척×200개, 환경 시드 166290927, 주차장/기존 에이프런 재사용, 건조 노면, 파도 OFF, unpaced 5 FPS, 같은 120개 화물 ID를 확인했다. 수정 전 기록에는 작업자 진입/제거 시험 1회가 포함되어 있으므로 아래는 과거 기록 대비 관측치이며 완전히 동일한 돌발상황의 통제된 A/B 결과는 아니다.

| 지표 | 최근 이전 기록 | 수정 후 |
|---|---:|---:|
| 마지막 야드 적재 | 9,397.55초 (156.63분) | 5,977.65초 (99.63분) |
| STS 평균 사이클, AGV 대기 포함 | 343.91초 | 212.87초 |
| STS 평균, 인양 후 AGV 대기 제외 | 300.93초 | 160.01초 |
| 인양 후 AGV 대기 평균 | 42.98초 | 52.86초 |
| AGV 교통 대기 평균 | 95.40초 | 47.48초 |
| 선박에서 배차 대기 평균 | 2,486.69초 | 1,724.74초 |
| 야드 완료 처리량 / STS 9대 평균 | 5.11개/h | 8.03개/h |

전체 마지막 적재 시각은 최근 기록보다 **36.39% 단축**됐다. 크레인이 빨라진 만큼 AGV를 기다리는 평균은 증가했으므로, 모든 대기가 줄었다고 해석하면 안 된다. 직접 복귀 인계 59회, AGV 48대 사용, 최대 동시 이동 20대, 120개 실제 적재와 차량 복귀·초기화까지 통과했다. 복귀 포함 6,065.8초다.

**25~30개/h 목표는 아직 달성하지 못했다.** 160.01초는 AGV 대기만 뺀 완료 작업 시간이며 역수인 약 22.5개/h를 실제 처리량으로 표시하면 안 된다. 120개로 제한한 검사에서는 일을 먼저 끝낸 STS의 꼬리 구간 유휴도 공통 분모에 포함된다. 전체 600개 연속 하역의 정상상태 처리량과 다르다.

수정 후 비위험물 102개는 3,797초 이내 적재됐으나, 인화성 10개·부식성 8개는 전용 RMG 43~46으로만 갈 수 있어 마지막 적재가 5,977.65초까지 늘어졌다. 이 수치는 해당 구역의 순수 RMG 작업 시간뿐 아니라 도착/선행 작업/도로 대기를 포함한다. 현재 접근권은 STS 배차부터 야드 작업 후 빈 AGV가 통로를 빠져나갈 때까지 독점된다. 이 독점 구간을 줄이려면 서로 막지 않는 실제 AGV 대기 공간과 진입/출구 예약을 함께 설계해야 한다. 예약 검사만 제거하면 기존 협소한 양방향 진입로에서 교착/정면 대치가 재발할 수 있다.

## 재현 및 기록

```powershell
./PortSim/Scripts/BuildPortSim.ps1
./PortSim/Scripts/TestSite.ps1 -Mode Normal -PlaybackRate 0 -FixedFPS 5 -TimeoutMinutes 45 -NoSea -CheckStowage -ResultSummaryPath ./PortSim/Saved/Tests/Throughput_Normal120.json
python PortSim/Scripts/MeasureThroughput.py PortSim/Saved/Results/Site_9320F8EB414FF070332ACB9B43FE2ED4.csv --log PortSim/Saved/Logs/SiteTest_Normal_Depot_Reused_47396.log --baseline PortSim/Saved/Results/Site_020653B04292555F7C371491010123F1.csv --output PortSim/Saved/Tests/Throughput_Comparison.json
```

- 운송: `Saved/Logs/SiteTest_Normal_Depot_Reused_47396.log`, `Saved/Results/Site_9320F8EB414FF070332ACB9B43FE2ED4.csv`.
- 요약: `Saved/Tests/Throughput_Normal120.json`, `Saved/Tests/Throughput_Comparison.json`.
- 단독 수평 제어 시험: 12/25/40m 와이어와 0/5m/s 바람, 20Hz 센서·120Hz 플랜트로 40m 이동과 정착/하중/흔들림 검사.
- 초기 검사에서 발견된 파도 집기 제어 전환 문제를 수정했다. 장시간 검사는 수정 전 36개에서 중단한 실행과 구분하며, 위 결과는 최종 운송 로직의 120개 완료 실행이다.
- 오래된 픽업 시험 준비 코드가 실제 AGV 동역학 속도 대신 표시용 `Speed`만 설정하던 부분과, 진단 정보가 추가된 오류 문자열을 완전 일치로만 검사하던 부분도 현행 계약에 맞췄다. 실제 실패 이유·화물 미부착 조건은 유지한다.
- 최종 빌드 성공. 네이티브 43개(`Throughput_FinalUnits.log`), 웹 32개, STS 픽업 8개·RMG 픽업/적재 11개가 통과했다. 파도, 편심, 위치 편향, 회전 오차, 착좌 누락, 잠금 고장, 센서 고장, 야드 높이 불일치, AGV 미정렬, 크레인 충돌 감지를 포함한다. 잘못된 조건에서는 부착/해제를 거부하는 것을 확인했다.
- 최종 120개 적재에서 규격 분리, 20ft 두 자리 완료 층 12개, 지지된 상부 적재 47개, 두 20ft 화물 AGV 운송 2회를 확인했다. 전체 600개 완료나 비·눈·결빙 조건의 처리량 시험은 아니다.
