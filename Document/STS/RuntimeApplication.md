# STS 레퍼런스의 런타임 적용

2026-09-24 원본 `main`의 `cca9a2f` 병합: 기본 화면은 중앙 시험 구역을 제거한 STS 9대·AGV 9대·RMG 36대 통합 항만이며, 선박 화물은 3척 총 1,584개다. 기존 중앙 STS 물리 경로는 `-PortSimLegacyTerminal`/중앙 테스트에서 유지한다. 아래 8대·1,064개 및 과거 시간 기록은 이전 배치의 검증 이력이다.

## 자동 운반에 적용되는 내용

| 입력 | 실제 적용 |
|---|---|
| 레일 간격·outreach·backreach | 크레인 다리/레일/빔 배치와 트롤리 이동 한계 |
| 인양 범위 | 작업 목표의 높이 검사와 현수 길이 한계. 지지 높이와 인양 기준점은 가정 파일에 명시 |

| 하중별 권상 속도 | 적재 질량에 따라 권상/하강 한계 결정. 빈 스프레더 조건 분리 |
| 메인 권상 모터 정격 출력 | 이상적 기계출력 상한을 이용한 권상 속도 제한. 모터 토크 곡선은 모델링하지 않음 |
| 가속도·저속 착지 속도·감속 거리 | 각 축의 가감속. 이동 구간은 부하별 속도를 사용하고 정지 거리를 고려해 착지 직전 감속 |
| 컨테이너 질량·무게중심 | 물리 바디의 질량/무게중심, 부하 조건과 하중 판정 |
| 트롤리/권상 엔코더 관측 | 자동 위치 제어 입력 |
| 착좌·잠금 상태 | 체결 및 적재 인양 허가 |
| AGV 위치·방향 | STS 하강/인계 허가 및 하강 중 정렬 유지 확인 |
| 화물 지지 관측 | 네 코너 아래 지지면 확인 후 체결 해제·인계 |
| 센서 유효성·주기 | 오래되거나 유효하지 않은 관측이면 자동 운반 중단 |

레퍼런스의 센서 목록을 읽고 필요한 6종을 검증한다. 현재 구현은 엔진 상태에서 생성한 **가상 관측**이며, LiDAR 광학 스캔이나 실제 엔코더 하드웨어 모델은 아니다. 스프레더/화물 자세와 지지면 관측은 자동화에 필요한 추가 합성 관측이다.

네 코너 하중은 질량·무게중심을 이용한 **준정적 분배 추정값**이다. 개별 로드셀의 실제 동적 반력, 개별 와이어 장력 또는 모터 토크를 계산했다는 의미가 아니다. 현수는 기존 Chaos 등가 제약을 사용하고 스프레더 회전은 여전히 잠겨 있다. 흔들림·속도를 확인한 뒤 착지하도록 하지만 제조사 anti-sway/anti-skew 제어기는 아직 구현하지 않았다.

## 실행

1. 저장소 루트에서 `PortSim/Scripts/BuildPortSim.ps1` 실행. 한글 경로에서 발생하는 MSVC 문제를 피하기 위해 임시 영문 junction을 만들며 원본은 이동하지 않는다.
2. 기존 `PortSim/Scripts/LaunchCrane.ps1`로 실행하면 기본 설정에서 초기 안정화 후 자동 하역을 시작한다.
3. U: 하역, L: 역방향 적재, P: 일시정지, Space: 비상정지, R: 초기화. 자동 시작을 끄려면 설정의 `auto_start_unload=false` 또는 실행 인자 `-PortSimManualStart` 사용.

반복 실행용 다른 입력은 `-PortSimSTSReference="경로"`, `-PortSimSTSSettings="경로"`로 지정한다. 잘못된 JSON, 필수 필드/단위 누락, 필수 센서 누락은 자동 운전을 막는다. 현재 기본 컨테이너는 기존과 같은 12t이며 모든 컨테이너에 같은 기본 사양을 적용한다.

하중별 권상 곡선은 도면에 주어진 loaded 점 사이를 선형 보간한다. 최저 loaded 점보다 가벼워도 빈 스프레더 속도로 외삽하지 않고 최저 점의 속도 87m/min을 유지한다. 이 정책 역시 명시한 가정이다.

## 기록과 해석

자동 작업마다 `PortSim/Saved/Results`에 다음 묶음을 생성한다.

- `Terminal_<방향>_<ID>.csv`: 완료 컨테이너, 질량, 작업 소요 시간, STS 동작·준비·AGV/RMG 후속 작업·일시정지 시간, 배치 경과 시간. `STSHandoverAtSeconds`는 STS 인계/배치 확인 시각, `FinalPlacementAtSeconds`는 최종 야드/선박 배치 확인 시각이다. 배치 경과 시간에는 AGV 복귀도 포함되므로 야드 적재 완료 시간에는 마지막 `FinalPlacementAtSeconds`를 사용한다.
- 같은 이름의 `_stages.csv`: 자동화 단계의 종료 시각·활성 시간·완료/중단 상태.
- 같은 이름의 `_profile.json`: 사용한 레퍼런스 전체와 가정 설정, 해석된 적재 한계.

기록은 시뮬레이션 시간이다. 배속에 따른 화면/컴퓨터 실행 시간 감소를 물류 시간 이득으로 계산하지 않는다. 중앙 시험 경로는 한 작업을 STS-AGV-RMG 순서로 완료한 후 다음 작업으로 넘어간다. 기본 통합 항만 경로는 여러 STS·AGV의 동시 운반, 도로 구간 예약 및 다음 화물의 선행 인양을 사용한다. 기준 운용 대비 시간 절감률은 아직 포함하지 않는다.

## 원본 항만 배치와의 통합

원본 `main`의 `569b9e9`까지 병합하여 전체 항만 배치, 선박 컨테이너 액터, 추가 STS/AGV/RMG 물류 흐름을 유지했다. 중앙 `AQuayCrane`의 레일 간격은 STS 프로파일을 따르고, 수면 크기는 원본의 확장 배치를 따른다. 중앙 STS 자동 시작은 프로파일 설정과 `-PortSimManualStart`를 따르며, 별도 `-PortSimSiteTest`에서는 시작하지 않는다.

후속 구현에서 중앙 `AQuayCrane`이 읽은 동일한 프로파일을 추가 STS 8대에 전달했다. 추가 STS는 `APortWorkingCrane::bSTS`로 구분하며, 야드 RMG 36대에는 STS 정격을 대입하지 않는다. 선박 컨테이너 액터 1,064개에도 기본 질량·무게중심을 적용한다.

추가 STS 적용 항목:

- 도면 기반 레일 간격·붐 범위·인양 높이와 목표 작업 범위 검사.
- 트롤리·갠트리·권상의 독립 속도/가속도, 하중별 권상 곡선과 출력 상한, 착지 감속.
- 시각·유효성·위치 편차가 있는 가상 관측, 착좌·4코너 잠금·하중 조건, 정지한 AGV의 위치/방향과 네 코너 지지면 확인.
- 센서 무효·잠금 실패·과부하·AGV 위치 이탈 시 인계 전 중단.

추가 STS는 기존 **운동학적 수평 스프레더 운반 모델**을 유지한다. 운반 중 화물을 부착하고 착지 시 물리 상태로 전환한다. 중앙 STS의 Chaos 현수 제약을 추가 장비에 복제한 것은 아니며, 추가 STS의 흔들림은 0으로 취급한다. 개별 와이어 장력이나 anti-sway/anti-skew 동역학을 계산했다는 의미가 아니다. 부하/센서/속도 조건은 이 모델의 이동 명령과 인계 판단에 실제로 사용한다.

추가 경로는 `Saved/Results/Site_<ID>.csv`에 컨테이너 ID, STS/AGV/RMG, 출발·STS 인계·최종 야드 적재 시각, 운반·STS·정지 시간, 질량을 기록한다. 같은 이름의 `_profile.json`은 레퍼런스·가정·운동학 모델을 기록한다. 여러 작업이 병렬 진행되므로 작업 시간을 단순 합산하여 항만 전체 소요 시간으로 사용하지 않는다. 초기화 시 기록 묶음을 새로 만든다.

`PortSim/Scripts/TestSite.ps1`는 정상 운반과 네 오류 시나리오를 검사한다. `-Mode Normal` 또는 `-Mode Faults`로 나누어 실행할 수 있다. 고정 0.05초 스텝에서 8대 STS가 각각 한 건씩 STS→AGV→RMG→야드 운반을 완료했고, 1,064개 액터 보존·정지/재개·운반 중 초기화·CSV 시각 순서 및 설정 스냅샷 검사를 통과했다. 최종 야드 적재 시각은 해당 8건 검증 배치 기준 1,029.050015초다. 센서 무효·잠금 실패·과부하·AGV 정렬 이탈 검사도 모두 통과했다. 전체 1,064건 소진이나 실항만 시간 절감률을 검증한 값은 아니다.

에디터 종료 후 UE 5.6 전체 빌드가 링크 단계까지 성공하여 이전 병합 시의 DLL 점유 문제는 해소됐다. 빌드 전에 작업을 저장하고 Unreal Editor 창을 닫으면 된다. Epic Games Launcher는 종료할 필요가 없다.

중앙 STS 통합 회귀에서는 24개 양하·24개 적하가 완료됐고, 양쪽 완료 후 액터 소유/슬롯 검사를 거쳐 초기화 단계까지 진입했다. 확장 장면에서 기존 도구의 10분 벽시계 제한에 걸려 전체 프로세스는 중단됐다. 완료된 두 CSV의 단계별 시간 합·누적 시간·인계 순서·프로파일 스냅샷을 별도 검사했으며 모두 통과했다. 최종 야드 배치 시각은 4,940.850074초, 역방향 최종 선박 배치 시각은 4,874.050073초였다. 이전 기록과 야드 배치가 달라 시간 절감 효과로 비교하지 않는다.

남은 검사는 `TestSTS.ps1 -Mode RegressionTail`로 분리하여 운반 중 STS/AGV/RMG 초기화, 독립 크레인, 센서/잠금/과부하 차단을 실행했고 모두 통과했다. 이 모드는 완료된 48건 운반을 다시 수행하지 않는다. 향후 전체 실행의 도구 제한은 확장 장면을 고려해 20분으로 늘렸다. 이 벽시계 제한과 시뮬레이션 내부 작업 제한은 별개다.
