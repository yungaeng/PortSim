# 센서 기반 STS 픽업

기본 통합 터미널의 `APortWorkingCrane` STS에 적용한다. 레거시 중앙 시험용 `AQuayCrane` 제어기는 별개다.

## 제어 흐름

1. 배정된 슬롯은 접근 위치로만 사용한다. 최종 픽업 목표는 관측된 화물 위치에서 계산한다.
2. 가상 카메라 시야 안에서 상대 위치·속도·yaw·기울기와 네 코너 오차를 검사하고 트롤리/갠트리/권상을 보정한다.
3. 네 코너의 접촉이 연속 확인된 뒤 각 잠금을 요청한다. 장치는 실제 접촉 조건과 작동 지연을 거쳐 개별 피드백을 반환한다. 명령 자체를 성공으로 취급하지 않는다.
4. 네 잠금 피드백이 모두 확인된 경우에만 현재 위치를 유지한 채 기계적으로 연결한다. 컨테이너를 스프레더 중심으로 순간 이동시키지 않는다.
5. 30 cm 시험 인양을 수행한다. 화물이 바닥 지지에서 벗어나고, 정지 상태에서 네 코너 하중이 유효하며 질량 추정이 안정되면 본 인양을 허용한다.
6. AGV 착지에서는 관측된 스프레더–화물 간격을 목표에 더해 픽업 때 보존한 부착 오차를 보정한다.
7. 정렬 실패는 제한 횟수만 재관측한다. 잠금 실패·센서 무효·시험 인양 실패는 정지하며 시간 경과로 성공을 강제하지 않는다.

`STSPickupController`는 액터/월드/실제 질량에 접근하지 않고 `FSTSObservation`만 받는다. 센서 생성과 접촉/잠금 장치 모델은 `STSPickupRuntime` 및 `WorkingCraneSTS`에 둔다. 이동 제어도 관측 위치·속도·흔들림 각속도를 사용한다.

## 하중과 추정

실제 질량/무게중심은 물리 플랜트가 가상 로드셀 힘과 모터·현수체 응답을 만드는 데 사용한다. 제어기는 `m_est = ΣF_corner / (g + a_z)`로 수직 가속도를 보정한다. 안정된 시험 인양에서 코너 위치에 하중 비율을 곱해 무게중심 X/Y를 추정한다. Z는 식별하지 않는다. 시험 인양 전에는 프로파일 기본 질량을 권상 속도 계획의 사전값으로 사용하고, 검증 후에는 추정 질량을 사용한다.

작업 배정 시 명시된 화물 질량의 유효성/정격 초과를 확인하는 기존 매니페스트 사전 검사는 유지한다. 이것은 센서 추정과 별개다. 개별 컨테이너의 질량/무게중심을 나중에 입력하면 플랜트 응답과 추정 결과에 반영되는 구조다.

## 설정

`PortSim/Config/STS_Simulation.json`의 `pickup_control`에 입력한다. 아래 값은 실물 장비 보증 사양이 아닌 시뮬레이션 가정이다.

| 항목 | 기본값 |
|---|---|
| 코너 수평 / 수직 허용 오차 | 2 cm / 2 cm |
| 상대 속도 / yaw / 기울기 | 3 cm/s / 0.25° / 0.5° |
| 연속 접촉 확인 / 잠금 작동 시간 | 0.7 s / 0.3 s |
| 정렬 제한 / 최대 시도 | 90 s / 2회 |
| 대상 탐색 반경 | 슬롯에서 1 m |
| 시험 인양 높이 / 안정 확인 | 30 cm / 1 s |
| 코너 최소 하중 비율 / 질량 변동 허용 | 3% / 2% |

도면 기준 STS 범위·속도·출력 및 기존 센서 제품 참조를 유지한다. 현재 고정 40ft 모델의 등가 코너 위치(±1 m, ±5.2 m)를 사용한다. 실물 코너 캐스팅 중심의 실측 좌표는 아니며, 실제 스프레더 기하가 확보되면 교체해야 한다.

## 웹 확인

장비 탐색기 → STS 선택 → **개요** 또는 **센서**. 픽업 단계, 대기/거부 이유, 코너별 XYZ 오차·접촉·잠금 요청/피드백, 시험 인양 추정 질량과 무게중심을 표시한다. 본 인양 허가와 단순 연결 상태는 구분한다. 이전 스냅샷에는 이 정보가 없으므로 새 빌드로 실행해야 한다.

## 모델의 한계

가상 카메라는 설정된 거리/FOV로 실제 위치를 관측값으로 변환하는 기하 모델이다. 영상 인식, 가림, 확률적 잡음, 선박 운동은 아직 구현하지 않았다. `pose_bias_*_m`으로 일정한 관측 편향을 주입할 수 있다. 접촉은 코너 기하 허용창을 판정하며 충돌 접촉 역학이나 잠금 구조 변형을 풀지 않는다.

코너 힘은 가속도와 무게중심에 따른 해석적 분배다. 지지면 아래에 질량 중심이 있으므로 양의 수평 가속도는 양의 축 코너 하중을 증가시킨다. 탄성 다물체/개별 로프-컨테이너 결합 해석이 아니다. 연결 이후에는 기존 현수체 모델과 액터 부착을 사용한다. 허용치를 넘는 화물 yaw는 거부하며, 화물 방향을 찾아 스프레더 목표 yaw를 조정하는 기능은 다음 단계다. 기존 anti-skew의 영점 안정화는 유지한다.

이 변경은 **픽업**에 집중한다. 경로 최적화, 하중을 반영한 전체 궤적 계획, AGV에 대한 새로운 정밀 착지 제어, 실측 기반 센서 보정은 후속 작업이다.

## 재현 시험

```powershell
./PortSim/Scripts/BuildPortSim.ps1
./PortSim/Scripts/TestSTS.ps1 -Mode Profile
./PortSim/Scripts/TestPickup.ps1
./PortSim/Scripts/TestSite.ps1 -Mode Normal
node --test Dashboard/tests/*.test.mjs
node Dashboard/tests/telemetry.mjs
```

픽업 집중 시험: 실제 위치 30/-20 cm 편차, 24톤 편심(25/-80 cm), 센서 편향, yaw 이탈, 접촉 누락, 대상 감지 실패, 잠금 실패. 성공 시험은 순간 이동 없음·피드백 선행·시험 인양 경유·추정 오차를 검사하고 실패 시험은 화물 부착 자체를 금지한다. 자동화 단위 시험은 접촉/피드백/지지/편하중 인터록 및 반복·만료 샘플의 거부를 검사한다.

## 검증 결과 · 2026-09-26

- UE5.6 Editor 빌드 성공. `ReferenceAndInterlocks`, `SensorPickup`, `SuspensionAndDrives` 자동화 시험 통과.
- 집중 런타임 시험 7개 통과. 위치 편차 보정 후 12,000 kg 추정, 편심 24,000 kg 화물에서 무게중심 X=25 cm/Y=-80 cm 추정. 편향·회전 이탈·접촉 누락·감지 실패·잠금 실패는 연결 전에 거부.
- STS 9기·AGV 60대의 120건 선박→STS→AGV→RMG→야드 운반 통과. 모든 STS와 AGV의 작업, 일시정지/비상정지, 운반 중·완료 후 초기화 포함. 마지막 적재 8,039.600120 시뮬레이션 초. 전체 1,584개 화물 완료나 실물 대비 시간 절감의 증거는 아니다.
- 실제 1,846개 엔터티의 웹 텔레메트리 검사와 시간 비교 계산 6개 시험 통과. 브라우저에서 STS 개요/센서 탭의 실제 관측 표시 및 실행 오류 없음 확인.
- 통합 고장 주입 4개(센서 무효, 잠금 실패, 과부하, AGV 정렬 이탈) 모두 인계 전 정지 확인.
