# STS 현수체·구동·장착 센서 모델

적용: 기본 통합 터미널의 `APortWorkingCrane` STS. 레거시 중앙 `AQuayCrane`, AGV 주행 모터, RMG 구동 상세 모델은 변경하지 않는다.

## 입력과 출처

도면 레퍼런스의 작업 범위·정격 속도·권상 2×335 kW를 유지한다. 새 `STS_Simulation.json`의 `dynamics`, `sensor_mounts`는 **제조사 미검증 시뮬레이션 가정**이다. 원본 센서 자료는 대표 부착 부위만 제공하므로 정확한 실물 설치 좌표를 알 수 없다. 좌표·방향·범위를 설정하여 엔진에 재현하는 기능을 구현한 것이며 실측 위치 복원이 아니다.

SI 단위 입력. 장착 XYZ는 gantry(크레인 루트), trolley(트롤리 중심), spreader(스프레더 중심) 기준 m. 회전은 Unreal pitch/yaw/roll 도, 로컬 +X가 측정축이다. 부모 메시 스케일을 보정해 설정한 m가 세계 거리와 일치한다. 트위스트록 하중/상태/착좌는 설정된 +X/+Y 코너와 대칭 3개 코너에 부착한다. 총 14종, 23개 마커이며 세계 좌표는 부품 움직임을 따른다.

## 현수체와 제어

내부 적분 간격 ≤1/240초, 이동 제어 ≤1/120초. 이동 제어는 매 외부 프레임을 균등한 하위 구간으로 나눈다. float 프레임 시간을 반복 차감할 때 남는 극소 구간에서 속도 보간의 정지 판정이 가속도를 증폭시키는 것을 방지한다. 로프 길이 L과 길이 변화율, 수평 이동축 가속도 a, 중력, 감쇠, 공기 상대 속도로 계산한 항력을 사용한다.

각 수평축: θ̈ = −(g sin θ + a cos θ)/L − (d + 2 L̇/L) θ̇ + Fwind/(m L).

2축은 작은 각도 근사로 분리한다. 계산된 편위를 스프레더와 부착 컨테이너 위치에 적용한다. yaw는 수직축 관성, 이상 현수 기하 복원 토크, 감쇠, 편심 관성 모멘트, 풍하중 모멘트와 PD 제어 토크를 적분한다. Anti-skew 토크는 설정 한계로 제한한다. Anti-sway는 양의 각속도 피드백을 이동축 가속도 명령에 더한다. 비활성화해도 자연 흔들림과 수동 감쇠는 남는다. 착지에는 위치·속도·흔들림·비틀림 허용치를 모두 요구한다.

진자 운동식의 기본 참고: [MIT Underactuated Robotics — Pendulum](https://underactuated.mit.edu/pend.html). 가변 길이, 이동축, 코너 분배 및 제어 연결은 본 프로젝트의 축약 모델이다.

## 와이어와 모터

Roll/pitch를 구속하고 4개 코너의 수직 반력을 질량, 무게중심, 이동 가속도에 따른 모멘트로 배분한다. 로프 방향의 수직 성분과 코너당 지지 구간 수 n으로 나눠 각 그룹의 **줄 하나당 장력**을 구한다. 정지 상태에서 Σ(n Tᵢ cos αᵢ)=mg. 이상 도르래는 같은 그룹 내 동일 장력으로 가정한다. `T × 길이 / EA` 신장은 진단 값이며 변위에 다시 적용하지 않는다. 음의 코너 지지력 또는 장력 한계 초과는 모델 범위 이탈로 정지한다.

권상 모터 축: K=n×감속비/드럼반경, ω=Vz×K. 각 모터 토크는 총 수직 하중/(K×효율×모터수)+회전관성×Az×K. 합계 축 동력은 모터수×토크×ω이며 하강 시 음수가 될 수 있다. 권상 명령은 RPM, 출력, 정적 하중과 가속 토크 여유로 제한하고 계산된 동적 포화 여부를 별도 표시한다. 회생 효율, 전류 및 열 모델은 없다.

현재 기본 가정: 드럼 반경 1.3 m, 감속비 24:1, 코너당 4개 지지 구간, 효율 0.9, 모터 2대. 공인 ZPMC 장비 사양으로 사용하면 안 된다.

## 센서와 웹

- 필수 합성 관측은 시뮬레이션 시간 20 Hz. 엔코더/하중의 설정 범위를 벗어나면 무효 처리한다.
- AGV 인계 단계에는 기존 위치·속도·방향 조건에 장착 센서의 원뿔 시야각·거리 조건을 추가한다. 픽업 전 멀리 있는 AGV의 준비 여부는 위치/속도 상태로 확인한다.
- 6종 광학/거리 센서는 가시성 충돌 채널에 대해 FOV 평면 내 9개 광선을 계산한다. 실제 시간 1 Hz 웹 내보내기용이며 카메라 영상 인식이나 3D 전방위 LiDAR가 아니다. AGV 범위 외의 광선은 자동 충돌 회피 제어에 연결하지 않는다.
- TTDS는 장착만 모델링한다. 신축 엔코더는 고정 40ft 형상 길이이며 신축 액추에이터는 없다. 풍속은 입력 벡터의 크기다.
- 웹 센서 화면: 장비 선택 → 센서 선택 → 실제 엔진 좌표 투영/설정 범위/관측·광선 확인. X/Z 투영에서 Y만 다른 센서는 겹칠 수 있어 목록도 제공한다.
- 웹 액터 물리 탭: 4줄 장력·추정 신장·모터 토크/RPM/동력·제어 ON/OFF·흔들림/yaw.

## 해석 한계

탄성 다물체 FEM, 로프 처짐·풀리 접촉 마찰·개별 드럼 제어·roll/pitch 자유 운동을 풀지 않는다. 큰 흔들림(20°)/비틀림(15°), 로프 이완은 중단한다. 실제 anti-skew 액추에이터 대신 한계가 있는 가상 yaw 토크를 사용한다. 이 모델로 계산한 운반 시간은 설정과 제어기에 따른 시뮬레이션 결과이며 실물 성능으로 검증된 시간 절감률이 아니다. 제조사 설치 도면, 로프 구성, 드럼/감속기/모터 곡선과 실제 동작 기록으로 보정이 필요하다.

UE 5.6 통합 회귀: STS 9대 / AGV 9대 / RMG 36대에서 18건 선박→야드 운반 완료. 최종 적재 1,214.000018 시뮬레이션 초, 최대 동시 주행 AGV 8대, 선행 인양 9건. 일시정지/비상정지/운반 중 및 완료 후 초기화 포함. 기존 운동학 모델과 제어·정착 시간이 달라 이 결과를 성능 향상으로 주장하지 않는다.

프로파일 및 `SuspensionAndDrives` 자동 테스트 통과: 정적 힘 평형, 편심 장력, 가속 하중과 모터 토크, 초기 yaw 교란 감쇠, sway 피드백 감쇠, 적분 간격 일관성, 로프 길이 12/25/40 m의 40 m 폐루프 이동 정착, 풍하중 변위, 모터 포화, 로프 과부하. 센서 무효/잠금 실패/과부하/AGV 정렬 이탈 주입 시 인계 전에 정지하는 4개 통합 고장 회귀도 통과했다.

웹 계산 규칙 6개 테스트와 실제 1,680개 엔터티 텔레메트리 검사를 통과했다. 이 검사는 STS별 센서 14종/마커 23개, 4줄 장력, 광선 거리 범위, 유한 수치와 스프레더 메시 스케일에 무관한 장착 거리도 확인한다.
